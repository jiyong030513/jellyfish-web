## 1단계: 모델 비교 (01_모델비교.ipynb)
- 입력 변수 11개 (제안서 3.6절): 통합, 통합_1주전, 통합_2주전, 통합_변화_1주, 연중주차, 수온_주평균, 수온_평년차, 수온_변화_1주, 기온_주평균, 풍속_주평균, 유의파고_주평균
  - 수온_변화_1주만 코드에서 생성 (같은 권역 4~10일 전 보고와의 수온 차이, v_학습데이터의 통합_1주전과 같은 기준)
- 제외: 분할이 '추가(2024)'인 20행
- 분할: 시작일 순서로 train 70% (2014-09~2021-07) / valid 10% (2021-07~2022-07) / test 20% (2022-07~2023-12)
- 결측: 정답이 빈 행은 예측기간별로 제외. 입력 결측은 로지스틱 = train 중앙값 대체 + 표준화, LightGBM·XGBoost = 그대로 입력
- 불균형: class_weight='balanced' (XGBoost는 scale_pos_weight)
- 비교 모델: 기준선(통합만), 로지스틱 회귀, LightGBM, XGBoost
- 하이퍼파라미터·최종 모델은 valid PR-AUC로 선택, test는 마지막에 한 번만 평가
- 최종 모델 선정 규칙: 1·2·4주 뒤 중 valid PR-AUC 1위를 가장 많이 한 모델 → 로지스틱 회귀 (2/3기간, valid 평균 0.546 / LightGBM 0.491 / XGBoost 0.472)
  - 1주 뒤는 LightGBM이 valid 1위(0.540 vs 0.435)였으나 test에서는 로지스틱이 높음(0.346 vs 0.258)

| 최종 모델 test | 행 / 급증 | C | AUC | PR-AUC | 재현율 |
|---|---|---|---|---|---|
| 1주 뒤 | 373 / 30 | 0.01 | 0.786 | 0.346 | 0.800 |
| 2주 뒤 | 352 / 29 | 0.3 | 0.763 | 0.306 | 0.759 |
| 4주 뒤 | 309 / 29 | 0.01 | 0.762 | 0.290 | 0.828 |

- 기준선(통합만) test PR-AUC 0.287 / 0.228 / 0.194 → 세 기간 모두 로지스틱이 높음
- 시각화 (노트북 11절): 모델별 ROC·PR 곡선 (test)

## 2단계: 서비스 모델 (서비스/05_서비스_로지스틱.ipynb)
- 모델 비교·하이퍼파라미터 탐색 없이 1단계에서 정한 것을 고정: 입력 변수 11개, 예측기간별 C (1주 0.01 / 2주 0.3 / 4주 0.01), 중앙값 대체·표준화·class_weight
- 학습 범위 FIT_ON
  - "train"(기본): 1단계와 같은 앞쪽 70%(2014-09~2021-07)만 학습 → 보고서 test 성능과 똑같은 모델 (확인 완료)
  - "전체": 정답이 있는 2014-09~2023-12 전체로 다시 학습 (최신 자료까지 반영하고 싶을 때)
- 예측 대상: 현재 통합 출현율이 50% 미만인 권역·주 1,849개 × 3기간 = 5,547행 (이미 50% 이상인 705개는 "급증" 질문이 성립하지 않아 제외, 제안서 3.6절 정의)
  - 2024년 5월 행도 예측에 포함 → 가장 최근 기준일은 2024-05-24
- 저장: 같은 모델명의 기존 예측을 지우고 새로 넣는 한 트랜잭션 (실패하면 롤백되어 기존 예측 유지)
- DB 연동 확인: 최종 DB(10번째 zip)를 처음부터 구축한 뒤 SOURCE="db", SAVE_TO_DB=True로 실행 → CSV 모드와 예측 5,547행 동일, 권역예측 테이블 저장값 일치, v_해수욕장예측위험도 270곳 조회 확인 (MariaDB 10.11에서 시험)

## 환경 요인 검증 (02_환경요인검증.ipynb)
- 환경 변수 6개(수온_주평균, 수온_평년차, 수온_변화_1주, 기온_주평균, 풍속_주평균, 유의파고_주평균)를 넣은 11개 모델과 뺀 5개 모델을 비교
- 두 모델 모두 하이퍼파라미터를 valid PR-AUC로 각각 다시 선택, test는 한 번만 평가
- test PR-AUC 차이는 test 행을 2,000회 복원추출(부트스트랩)해 95% 구간으로 불확실성 표시

| 로지스틱 | valid PR-AUC 포함 / 제외 | test PR-AUC 포함 / 제외 | test 차이 95% 구간 |
|---|---|---|---|
| 1주 뒤 | 0.435 / 0.455 | 0.346 / 0.347 | −0.076 ~ 0.080 |
| 2주 뒤 | 0.519 / 0.516 | 0.306 / 0.268 | −0.043 ~ 0.101 |
| 4주 뒤 | 0.684 / 0.644 | 0.290 / 0.325 | −0.186 ~ 0.103 |

- 결론: valid에서는 2·4주 뒤에 환경 변수를 넣은 모델이 높았고, test에서는 기간마다 엇갈림. 세 모델(로지스틱·LightGBM·XGBoost) 모든 차이의 95% 구간이 0을 포함 → 출현율·계절 정보 위에 환경 변수가 더하는 예측력은 이 자료에서 확인되지 않음
- 최종 모델은 valid 기준 절차대로 11개 변수 모델을 유지 (test 결과를 보고 변수를 바꾸지 않음)

## 상관 분석 (03_상관분석.ipynb)
- 대상: 2014-09~2023-12 전체 2,534행 (변수 선택에 쓰지 않는 설명용 분석)
- 수온 vs 통합 출현율: 피어슨 0.46, 스피어만 0.48. 수온 구간별 평균 출현율 12℃ 이하 5% → 20~24℃ 36% → 24℃ 이상 약 48~50%
- 수온 평년차 vs 통합 출현율: 0.16 (약함)
- 같은 달 안에서 보면 수온과 출현율의 상관이 −0.01~0.33으로 약해짐 → 수온과 출현율의 관계 중 상당 부분이 계절(여름) 효과
- 입력 변수끼리 강한 상관(|r| ≥ 0.7): 수온–기온 0.89, 풍속–파고 0.78, 통합–통합_1주전 0.76, 통합_1주전–통합_2주전 0.76

## 변수 선정: 처음 14개 → 최종 11개 (04_상관기반_변수제거.ipynb)
- 처음 14개(1차 모델): 월, 연중주차, 노무라, 보름달, 기타, 통합, 통합_1주전, 통합_2주전, 통합_변화_1주, 수온_주평균, 수온_평년차, 기온_주평균, 풍속_주평균, 유의파고_주평균
- 제거: 월(연중주차와 상관 0.99), 노무라·보름달·기타(통합 출현율을 계산하는 재료라 통합 하나로 대표, 노무라–통합 0.76). 추가: 수온_변화_1주(제안서 3.6절)
- 처음 14개로 되돌려도 valid PR-AUC 변화 −0.027 (95% 구간 −0.087 ~ +0.047) → 11개로 줄여도 성능 손실 없음
- 남은 11개 안의 상관 쌍 검토: train으로만 상관 계산 → |r| ≥ 0.7인 4쌍에서 정답과의 상관이 약한 쪽을 제거 후보로 선정
- 후보를 하나씩·함께 뺀 모델의 C를 valid로 다시 고르고, valid PR-AUC 평균(1·2·4주)과 부트스트랩 95% 구간으로 판단

| 변수 조합 | 변수 수 | valid PR-AUC 평균 | 변화 (95% 구간) | 판단 |
|---|---|---|---|---|
| 전체 (현재) | 11 | 0.546 | 기준 | - |
| 처음 14개로 되돌리기 | 14 | 0.518 | −0.027 (−0.087 ~ +0.047) | 11개로 줄여도 차이 없음 |
| −수온_주평균 | 10 | 0.555 | +0.009 (−0.014 ~ +0.035) | 유지 |
| −유의파고_주평균 | 10 | 0.554 | +0.008 (−0.021 ~ +0.042) | 유지 |
| −통합 | 10 | 0.536 | −0.010 (−0.052 ~ +0.040) | 유지 |
| −통합_2주전 | 10 | 0.555 | +0.009 (−0.031 ~ +0.060) | 유지 |
| −통합 외 후보 3개 | 8 | 0.564 | +0.019 (−0.028 ~ +0.065) | 유지 |
| −후보 4개 모두 | 7 | 0.552 | +0.006 (−0.048 ~ +0.063) | 유지 |

- 결론: 14개로 되돌리거나 상관 높은 변수를 빼도 valid 성능 차이가 우연 범위 안(모든 구간이 0 포함) → 입력 변수 11개 확정 (비교 모델·서비스 모델 동일)
- test PR-AUC는 참고로만 기록(변수 선택에 사용하지 않음)
